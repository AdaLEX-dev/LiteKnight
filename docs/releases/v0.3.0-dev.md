# LiteKnight v0.3.0-dev

**Version:** `0.3.0-dev`
**Tag:** `v0.3.0-dev`
**Status:** native 1080p UI, Living Room hub, room transition, equipment and persistence

## Highlights

- True 1920×1080 logical 16:9 UI contract with framebuffer letterboxing.
- Recovered `pixel_bold` font atlas with measured glyph advances, alignment,
  multiline text, shadow/outline and pixel snapping.
- Top-left HP/armor/energy HUD and two-slot weapon strip.
- Empty equipment state; no weapon renders when no weapon is equipped.
- Physical weapon pickup with `E PICK UP` prompt and active-slot replacement.
- Two weapons with `1`/`2`/`Q` switching.
- Pause, Settings, Main Menu, character station and weapon station screens.
- Recovered Living Room hub from HeroRoom level data: tilemaps, NPCs, props,
  collision, character/forge stations, garden foundation, hub door.
- State-preserving room transition between Living Room and `r1_1`.
- Death clip playback, hit flash and render interpolation at 60 FPS with 50 Hz
  simulation.
- Save v2 with hub/settings/progression fields and v1 migration.

## Not claimed complete

- Procedural dungeon generation and full event-listener parity.
- Full EnemyAI04/pathfinding and additional enemy integration.
- Production forge recipes, plant economy, NPC dialogue/schedules.
- Recovered HUD icon sprite mapping (native parity icons used).
- Effects/items/audio and the full recovered catalogue.
- Social features are intentionally absent.
