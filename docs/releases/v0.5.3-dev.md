# LiteKnight v0.5.3-dev

**Version:** `0.5.3-dev`
**Date:** 2026-11-01
**Focus:** Content reconstruction and hub/combat integration.

## Highlights

- Living Room now loads the default active HeroRoom hierarchy. Inactive event
  tilemaps/objects (for example `chinesenewyear_wall_lobby`) and seasonal tokens
  are excluded. The garden, workshop/research and cellar are physically
  reachable from spawn; the hub topology audit reports 94.9% of walkable floor
  cells reachable and zero baked event instances.
- Dungeon doors are sealed when the current room has no matching map edge, so
  physical openings, door state and the room graph cannot disagree.
- Fixed per-room texture ID collisions that rendered the Living Room with the
  previous room's atlas after a transition.
- Dungeon rooms have a real return portal using the recovered
  `transfer_gate_02` six-frame 12 fps clip. `E` then `E` within 3 s confirms and
  returns through the normal `ActivateRoom` path to the Living Room. Hub stats
  refill on return.
- Body facing now follows movement horizontally while weapon aim stays
  independent; idle facing follows aim. c00 has only side-view idle/run/dead/hit
  clips, so no fake up/down animations were added. Render aim interpolation and
  a hand-side grip reduce walking weapon wobble.
- Knight ability charge uses the recovered `UICanvas.UpdateSkillMask`
  `Image.fillAmount` mechanism: dark `ui_joy_2` base, blue clipped `ui_joy_3`
  fill, full blue ready state and `ui_joy_7` recharge marker.
- Weapon catalogue: 302 entries loaded; 15 Tier A weapons fully integrated with
  localized names, actual damage/energy, projectile, visual, hand binding and
  attack cadence. 281 Tier B and 6 Tier C entries are explicitly classified.
- Chest catalogue: 13 classes / 86 GameObjects audited. chest00/01/02 integrated
  with actual visuals, `chest_open` 1.0 s animation, `RGChestAppoint` fixed
  weapon loot and `WeaponDropInfo` weighted level tables.
- Room metadata: integrated r1 rooms expose `RGRoomX.room_type=1`, `1-1`/`1-2`/
  `1-3` labels and `CLEARED`; the minimap consumes room types and shows the
  white-D devroom cell.
- Main menu remains upper-left `LIGHT KNIGHT`, left-aligned vertical button
  stack, recovered frames; NEW GAME text is white. UI 0.5.2 assets are retained.
- Review harness extended with `workshop`, `garden`, `cellar`, `chest`,
  `weapons`, `devroom` and existing areas.
