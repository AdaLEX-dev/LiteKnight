# LiteKnight v0.5.4-dev

**Version:** `0.5.4-dev`
**Date:** 2026-11-01
**Focus:** reference-data reconstruction and major systems foundation.

## Highlights

- Main menu is the default launch path (`liteknight-devroom` now starts the main
  menu). D-ROOM is upper-right; **S/L** is adjacent to New Game. Settings no
  longer draws the gear icon on the main menu.
- Native Save/Load screen for slot 0 with character/scene/weapons/HP/orbs/
  playtime/seed summary. ESC opens/closes pause correctly; pause icon moved up.
- Removed the timed 30-second review harness and its freeze flow. Direct
  `scripts/play-area.sh <area>` launches run until the window is closed.
- Living Room cleanup: staircase/cellar, cellar trigger/locks, tutorial arrow,
  Drillmaster, opposite seller, promotion pair, floating orb, lower portals,
  boss-rush guardian and every `biaoqing_16` `(!)` tab removed. Event instances
  remain zero. Central table collision is audited.
- Weapon pipeline expanded from 15 to **168** automatically extracted standard
  projectile weapons. 49 melee-pending and 85 unique/catalogue-only entries are
  explicitly classified. Multi-shot `multiCount`/spread is implemented.
- c00 hand mounts confirmed: h1 `(0,0.5)`, h2 `(0.55,0.6)`, h3 `(0.15,0.85)`.
  Weapon depth now sorts against the character feet, fixing the hidden weapon.
  Knight dual wield now uses a real second weapon and h2 rendering.
- Baseline Knight **Bad Pistol (weapon_000)** is equipped on entry instead of
  being an unsupported floor pickup.
- Orb currency: separate save field, actual `ui_52` gem icon only in the Living
  Room, orb trader with three actual weapon offers priced by serialized
  `item_value`, purchase/insufficient/SOLD states.
- Audio: 11 actual reference clips exported and wired through the existing
  miniaudio engine: UI, pause, pickup, chest, gun, hit, door, transition, hub
  and dungeon BGM.
- Chests: normal-room chests wait for room clear, spawn at the deterministic
  chest position and auto-open on proximity. Chest loot uses recovered
  `WeaponDropInfo` and opens over 1.0 s.
- Catalogues: 18 MapManagerLevel configs, 108 PatternRoom sizes/types, 102
  enemy prefabs with 77 biome assignments.
- Save schema v3 adds orbs and migrates v0/v1/v2.
