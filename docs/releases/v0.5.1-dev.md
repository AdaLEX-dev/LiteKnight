# LiteKnight v0.5.1-dev

**Version:** `0.5.1-dev`
**Status:** presentation repair, logical HUD editor, map, chests and world coins.

## Highlights

- Y-depth foreground resolution for character/WallFont sprites fixes the
  player-head clipping produced by static Unity sorting layers.
- HUD moved to a data-driven logical 1920×1080 layout: status rows flush at the
  upper-left, coin/pause at the upper-right, weapon strip and larger ability
  button at the lower-left, map under the pause/coin cluster.
- Persistent UI Design Mode from Settings. Every HUD element is draggable with
  the mouse, saved to `$XDG_CONFIG_HOME/liteknight/ui_layout.json`, reset with
  `R`, and remains correct through fullscreen/letterbox transforms.
- LIGHT KNIGHT main-menu wordmark, left-edge alignment repair and an opaque
  blue D-ROOM developer button in the upper-left.
- The test executable now starts at the normal main menu by default.
- Persistent minimap plus full map overlay (`M`) with room cells, links,
  current/visited state and a white-D devroom marker.
- Fresh configuration defaults to Auto Aim; Manual remains selectable.
- Weapon presentation scale increased without changing muzzle/projectile or
  collision data.
- Actual chest00 and RGCoin assets: closed/open chest, one-shot coin loot,
  four-frame coin spin, magnet/pickup, HUD wallet and session room state.
- Actual 1920×1080 bordered fullscreen validated: drawable 1920×1080,
  viewport 1920×1080 at (0,0), scale 1.0, mouse center -> (960,540).
- 148 doctest cases / 5,236 assertions; CTest 3/3, Debug ASan/UBSan and Vulkan
  validation clean.

## Evidence boundary

`CONFIRMED`: c00 SkillInfo values; coin RGCoin type/value/speed/range and
animation frames; chest00 prefab children/RGChest level; 1920×1080 viewport
contract; fresh save defaults.

`HYPOTHESIS`: native Y-depth rule, default HUD anchors, minimap layout and
open key, chest lid animation and one-coin loot, weapon 1.5× display scale.

`UNKNOWN`: exact reference HUD pixel anchors, full room-icon atlas, RGChest loot
tables, reference map key and full MapManagerLevel generation.

## Known limitations

- Reference `MapManagerLevel.CreateMap` remains unimplemented; the native graph
  uses the three integrated PatternRooms.
- Chest/remaining-coin room state is session-scoped; the wallet is saved but a
  full room-state save requires v3.
- UI panel/ribbon frames and main-menu background remain native compositions.
- Exact charge/cooldown visual animation data for the c00 skill button is not
  recovered; the native fill is state-driven.

Reference-derived pixels remain `LOCAL_ONLY`, `REFERENCE_DERIVED`,
`NOT_FOR_REDISTRIBUTION`. Native source is MIT. LiteKnight is unofficial.
