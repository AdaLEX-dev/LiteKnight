# LiteKnight v0.2.0-dev

**Version:** `0.2.0-dev`
**Tag:** `v0.2.0-dev`
**Status:** native Linux devroom / asset laboratory / interactive test lab

## Highlights

- Full local reference catalogue: 365 textures, 6408 sprites, 365 unique
  weapon IDs, 125 unique enemy IDs, 2098 animation clips and 54,891 GameObjects.
- Asset laboratory (`--asset-lab`, `F5`) with category/item cycling, real
  sprites and metadata, animation playback and test actions.
- Serialized interactive tests with a real Wayland/Vulkan window, per-tick input
  recording, state samples, named scenarios, replay and `test-results/*.json`.
- Live enemy pursuit/contact combat with multiple slimes, player HP/armor,
  damage, death and deterministic reset.
- Recovered c00 energy (180), per-shot weapon consumption, and native HUD bars.
- Two independent weapon slots with `1`/`2` switching and real projectiles.
- World weapon-pickup foundation (`G` spawn, `E` pickup) using recovered weapon
  sprites.
- Versioned native save/load (`F2`/`F3`) using
  `$XDG_DATA_HOME/liteknight/saves/slot_0.json`, atomic writes, backup fallback
  and migrations.
- Asset audit reports under `analysis/assets/audit-report.{json,txt}`.

## Known limitations

- Room transitions, start GUI and hub are not implemented.
- Effects/UI/items/plants/audio reference categories remain UNRECOVERED.
- The 5x7 developer text atlas is PLACEHOLDER UI.
- Only four recovered weapons and one enemy definition are integrated.
- Full EnemyAI04 scouting/pathfinding, forge/recipes, plants and production
  progression are UNKNOWN.
