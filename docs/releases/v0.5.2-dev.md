# LiteKnight v0.5.2-dev

**Version:** `0.5.2-dev`
**Date:** 2026-11-01
**Focus:** UI emergency polish, reference asset recovery, weapon metadata, VSync
and manual visual-review tooling.

## Highlights

- Recovered and integrated the actual main-menu `biaoti 01` backdrop (including
  the Knight silhouette/light beam) and `biaoti 02` red swirl. Arbitrary native
  red rectangles were removed.
- Rebuilt main-menu composition: LIGHT KNIGHT wordmark, clean vertical button
  stack using actual `ui_btn5/7/1/4` frames, centered labels, corrected D-ROOM
  hitbox, and no left-edge artwork clipping.
- HUD now uses the actual `ui_15` status plate, `ui_12` bar fills, `ui_31` coin,
  `ui_94` pause icon and `ui_joy_0/3/7` lightning ability construction.
- Pause/settings use recovered `ui_2`, `ui_13`, `ui_22`, `ui_38`,
  `ui_btn1/3`, `ui_98/92/93` and related assets. Every settings label/value is
  inside its row; button and heading text is measured, centered and pixel
  snapped through one global logical-pixel text path.
- Compact minimap reconstructed from `UIMap`: reference tinted cells and
  connectors, recovered `ui_4` target marker and recovered boss/special/chest/
  home/cage icons. The native white-D devroom cell remains one normal cell. The
  fullscreen map/`M` overlay was removed.
- Weapon pickups now show recovered localized names (`Bad Pistol`, `AK-47`,
  `Next-gen SMG`, `Revolver Gold`), icons, damage and per-attack energy cost.
  `tools/asset/audit_weapon_catalogue.py` recovers a 302-name catalogue and
  serialized stats for 296 prefabs.
- Weapon display scale is now the serialized prefab scale `1.0`; the 1.5x
  experiment is retired.
- FIFO VSync remains enabled; present mode, display refresh and measured present
  intervals are logged. Release smoke measured 60.08 Hz average; fullscreen
  measured 1920x1080 drawable/viewport at scale 1.0 with zero borders.
- Added `scripts/test-explore.sh <area>`: a 30-second manual exploration test
  that freezes the real application, prints `REVIEW REQUIRED`, and waits for
  ENTER before resuming.

## Validation

- 151 doctest cases / 5,255 assertions.
- CTest 3/3.
- Debug ASan/UBSan tests and devroom smoke clean.
- Vulkan validation clean in the debug smoke.
- Fullscreen: drawable 1920x1080, viewport 1920x1080 at (0,0), scale 1.0000x,
  borders L0 R0 T0 B0.
- r1_1, r1_2 and r1_3 now load for visual review; decorative non-solid
  `skin_trap` markers no longer abort room initialization.

## Explicitly not claimed

- An exact LIGHT KNIGHT title artwork (none exists; the recovered title is
  Chinese/Soul Knight branding).
- Full-room special-icon metadata beyond the integrated `home` room.
- Full per-weapon cadence outside the four integrated weapons.
- Save v3 per-room item state and the exact `RGChest` loot table.
- Reference-perfect chest loot. The existing one-coin deterministic native
  extension is retained.
