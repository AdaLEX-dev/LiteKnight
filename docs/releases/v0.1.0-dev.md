# LiteKnight v0.1.0-dev

- **Version:** `0.1.0-dev`
- **Date:** 2026-10-31
- **Commit/tag:** see the tag `v0.1.0-dev`
- **Build:** CMake, C++20, SDL3, Wayland, Vulkan 1.3, Linux

## Features

- Permanent native devroom executable (`build/bin/liteknight-devroom`)
- One-command build/test/launch workflow (`scripts/dev.sh`)
- Developer overlay and selectors for characters, weapons and enemies
- Four recovered Gun001 weapons with real weapon textures:
  `weapon_000`, `weapon_002`, `weapon_048`, `weapon_287`
- Real projectile sprites and deterministic swept collision
- Character selector for all recovered `c00..c14` with real body sprites and
  idle/run clips
- Enemy selector/spawner for `e_slime01`, spawn one/five/clear
- Player damage/death and deterministic reset
- Animated doors, obstacle switching, camera, room topology
- Asset inventory and metadata audit pipeline

## Recovered systems

- Held attack path, weapon Animator cadence, spread formula, projectile/damage
  path, e_slime01 contact/death data, player RoleAttributePlayer stats.
- See `analysis/re/combat_prototype.md`.

## Assets

- 14 native texture records / 182 sprites integrated from local reference data.
- Four weapons, one enemy, 15 characters, four doors, 12 obstacle variants.
- Reference-derived pixels are local-only and not distributed.
- Developer text font is a native PLACEHOLDER pending a licensed/recovered UI font.

## Known limitations

- No full enemy AI, room clear, procedural generation, room transitions, items,
  production menus/UI/game-over/reborn, audio, or full weapon/enemy catalogue.
- Only 4 of 383 observed weapon GameObjects and 1 of 126 enemy IDs are integrated.
- Character selector is a developer UI, not production character selection.
- Combat uses native swept linear projectile collision, not full Unity Physics2D.

## Testing

- 87 test cases / 4796 assertions in RelWithDebInfo and Debug ASan/UBSan at the
  time of release.
- Vulkan validation clean.
- Wayland/Vulkan devroom smoke and real-input combat/reset verified.
