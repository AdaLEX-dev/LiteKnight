# Asset Pipeline

**Status:** **PARTIAL / Unity-derived sprite-scene, idle/run animation,
and locomotion gates PASSED.**
The native PNG → RGBA8 → Vulkan texture path, one controlled Unity Texture2D
conversion, Unity Sprite metadata, camera/world transforms, a native `r1_1`
reconstruction test scene, the real `c00` idle/run AnimationClips, and a keyboard
locomotion slice are implemented and verified. The full asset catalogue, general KTX2/atlas packing, full
AnimatorController semantics, audio conversion, and the full asset registry are
not implemented.

**Canonical representation:** `engine::assets::TextureData`
(`src/engine/assets/TextureData.hpp`).

```text
UnityPy Texture2D → deterministic PNG → libpng
future KTX2 / future converted Unity texture
                │
                ▼
        TextureData (RGBA8, top row first)
                │
                ▼
        Texture2D staging upload
                │
                ▼
        VkImage → view → sampler → descriptor
                │
                ▼
        SpriteBatch / SpriteRenderer
```

The renderer receives RGBA8 bytes and does not know the source format.

---

## 1. Decoder and dependency

- Library: **libpng** (`libpng16`), via the system package and `pkg-config`.
- Expected CachyOS/Arch development package: `libpng`.
- CMake: `pkg_check_modules(LIBPNG REQUIRED libpng>=1.6)`.
- Tested against libpng **1.6.59**.
- License: libpng-2.0 (permissive PNG Reference Library License); no libpng source
  is vendored or committed.
- The project uses libpng's simplified read API, which normalizes supported PNG
  inputs to `PNG_FORMAT_RGBA`:
  - RGB → RGBA (alpha 255),
  - RGBA preserved,
  - grayscale → RGBA,
  - grayscale+alpha → RGBA,
  - palette and tRNS → RGBA.
- No PNG parser is implemented in this repository.

Alternative libraries were considered. libpng is already a mature system
dependency on the target distribution, has a stable C API, and avoids vendoring
a large decoder. The dependency is declared in CMake; there is no undeclared
machine-local library use.

## 2. Canonical texture contract

```cpp
struct TextureData {
    uint32_t width;
    uint32_t height;
    std::vector<uint8_t> rgba8;  // tightly packed R,G,B,A
};
```

- Byte order is **R G B A**, 8 bits per channel.
- Row order is top row first.
- `rgba8.size()` must equal `width * height * 4`; `IsValid()` checks this.
- The `std::vector` owns the pixels. `TextureData` is movable; no raw pixel
  pointers are retained by the renderer.
- The decoder clears the output before attempting a decode. Failure returns
  `false`, reports a non-empty error, and leaves no blank/zero-filled texture.
- Decoder limits: max dimension 16384; max pixel buffer 512 MiB.

## 3. Native upload and lifetime

`Texture2D::CreateFromTextureData` delegates to the existing
`CreateFromRGBA8` staging path. No PNG-specific Vulkan code exists.

- Staging buffer: host-visible/coherent, copied to a device-local
  `R8G8B8A8_SRGB` image.
- Image transitions: `UNDEFINED → TRANSFER_DST_OPTIMAL →
  SHADER_READ_ONLY_OPTIMAL`.
- Image view + sampler + descriptor set feed the existing sprite pipeline.
- On shutdown, the descriptor pool is released before the sampler/image, then
  the Vulkan context waits idle before destroying device resources.
- The decoded `TextureData` may be released after upload; the GPU owns the image
  lifetime through `Texture2D`.

## 4. Runtime path resolution

The application uses the existing `platform::FileSystem` search order:

1. `$XDG_DATA_HOME/soul-knight/assets`
2. executable-relative `assets/`
3. `/usr/share/soul-knight/assets`

CMake copies the synthetic test assets and compiled shaders into
`build/assets/{test,shaders}`. Running the executable from a different working
directory therefore still finds the same files. No developer home-directory
path is hardcoded.

For installation, the same files must be installed under
`share/soul-knight/assets/{test,shaders}` (the test assets are development-only).

## 6. Controlled Unity Texture2D conversion

`tools/asset/extract_unity.py convert-texture` extends the existing UnityPy
extraction pipeline. It does not add a second asset architecture.

- UnityPy: **1.25.4**, pinned in `tools/asset/requirements.txt`.
- Pillow: **13.0.0**, pinned for deterministic PNG writing/decoding.
- Converter version: **1.0.0**.
- Accepted formats: `RGBA32`, `RGB24` only.
- Mip count must be 1; ambiguous/mipmapped textures are rejected.
- Source `Texture2D.image` → Pillow `RGBA` → top-row-first canonical bytes.
- Output PNG uses `optimize=False, compress_level=9` and no timestamp metadata.
- The converter re-opens the PNG and verifies exact RGBA8 equality before
  recording the conversion.
- No proprietary bytes are committed; the PNG and raw RGBA dump live under
  gitignored `assets/generated/texture-conversion/`.

rendered through the existing `--texture` runtime path. The source has eight
transparent top rows and sixteen opaque brown rows; the rendered tall quad shows
the transparent upper region and brown lower region, making orientation and alpha
visible. The temporary screenshot evidence is not committed.

## 9. Current limitations

- No KTX2/atlas packing or mipmaps.
- No full asset registry/manifest loader.
- Only the controlled `r1_1`/`c00` visual subset is converted. The selected
  idle/run clips are imported; other clips, states, transitions, and the full catalogue
  are not.
- Tight polygon `m_VertexData` meshes are approximated by adjusted rectangular
  crops; border/nine-slice rendering is not applied.
- The native animation model implements one SpriteRenderer track and discrete
  sprite samples; generic curves, blend trees, layers, events, and IK are out of
  scope.
- `r1_1` wall/door gap placement, door barriers/triggers and one-way closed-door
  collision are reconstructed. Remaining gaps: exact runtime entrance bits for a
  generated `r1_1`, the event-to-`MapManagerLevel` traversal listener, door
  transition timing, and adjacent-room generation.
- No Unity-derived bytes are committed; generated PNG/RGBA outputs are ignored.
- The synthetic smoke image remains the default renderer fixture.
- Installed-asset shader/test discovery has not yet been exercised by a package.
- Audio conversion remains separate.
